# 功能清单

## 1. 串口连接管理

| 编号 | 功能 | 说明 | 验收标准 |
|------|------|------|----------|
| F1.1 | 串口枚举 | 列出本机所有可用串口；自动识别 CH340 系列设备（VID `1A86`，PID `7523`/`5523`）并标记 | 打开页面即返回端口列表；CH340 设备带标识；支持手动刷新 |
| F1.2 | 串口参数配置 | 波特率（默认 9600，提供常用值下拉）、数据位（默认 8）、停止位（默认 1）、校验位（默认 None）、流控制（默认 None）；打开模式固定为读写 | 修改后立即生效于下次打开；参数经浏览器 localStorage 持久化 |
| F1.3 | 打开/关闭串口 | 点击"打开"按当前参数连接；失败时给出具体原因 | 已打开时按钮变为"关闭"；打开失败提示原因（权限不足时附带 Linux `dialout` 组解决方案；设备占用、不存在等均有对应文案） |
| F1.4 | 资源可靠释放 | 程序退出（含 Ctrl+C）时自动关闭串口；打开新端口前自动关闭旧端口 | 退出后无 "device busy"；重复打开不报占用 |
| F1.5 | 连接状态广播 | 串口打开/关闭/异常断开状态实时推送至所有已连接的浏览器页面 | 任一页面打开串口，其他页面状态同步；设备拔出时所有页面收到断开提示 |
| F1.6 | 串口热插拔监听 | 服务端轮询枚举（2 秒周期），端口列表变化时经 WebSocket 推送 `ports` 消息；已打开的端口被拔出时自动关闭并广播原因 | 软件运行中插入 CH340，下拉框数秒内自动出现新设备（无需手动刷新）；拔出已打开设备时页面显示断开提示 |
| F1.7 | 多客户端打开/关闭同步 | open/close 幂等：重复打开同一端口视为成功（no-op）；串口未打开时关闭视为成功；打开/关闭结果广播所有客户端 | 两个页面同时点打开/关闭不报错、状态最终一致；打开不同端口时旧连接安全关闭并广播 |

## 2. 继电器控制面板

| 编号 | 功能 | 说明 | 验收标准 |
|------|------|------|----------|
| F2.1 | 模块路数选择（每客户端本地） | 支持 1/2/4/8 路模块，默认 1 路。路数是**各 GUI 实例的本地展示偏好**（localStorage 持久化），服务端不保存；打开串口/刷新状态/全开全关时随请求携带本实例路数，服务端据请求逐路执行 | 切换路数仅影响本实例：立即重绘卡片；不同客户端可各设 1 路/4 路互不干扰；未连接时也可先设置 |
| F2.2 | 全通道状态显示 | 打开串口并选择路数后，逐路发送查询指令（0x05）刷新所有通道逻辑状态；状态图标区分开/关 | 每个通道卡片显示实时逻辑状态；查询失败的超时通道标记为"未知" |
| F2.3 | 单通道开关控制 | 每个通道卡片提供 **switch 主控开关**（主要控制方式）与 开/关 按钮，使用带反馈指令（开=0x03，关=0x02）下发，以硬件回包确认状态 | switch 切换后 ≤200ms 内得到确认或超时提示；状态与硬件反馈一致 |
| F2.4 | 单通道切换 | 每通道提供"切换"按钮（原"取反"），发送 0x04 | 切换后状态正确刷新 |
| F2.5 | 全开/全关 | 提供"全部开启"/"全部关闭"快捷按钮，按通道顺序逐路下发 | 顺序执行，全部完成后统一刷新状态 |
| F2.6 | NO/NC 接线映射（每 GUI 实例本地视角） | 接线方式是**每个 GUI 实例（浏览器）的本地视角**，每通道独立设置 NC（常闭，默认）/NO（常开），切换即时生效。服务端只维护物理状态（00=线圈释放/01=线圈吸合）并全局广播；各实例按本地视角独立推导逻辑显示：NC 视角 00=逻辑开、NO 视角 00=逻辑关。on/off 指令随请求携带本地视角，服务端无状态映射为物理指令 | 同一物理状态在两个 GUI 实例（不同接线视角）下独立显示且各自正确；切换视角即时重映射、无需重查；物理状态标注（物理00/01）所有实例一致 |
| F2.7 | 高级按钮显隐 | 通道卡片上的 开/关/切换 按钮默认收起，展开后按钮上方标注“独立指令下发：”；通过**每张通道卡片右上角的箭头图标（▸ 收起 / ▾ 展开）**独立展开/收起；switch 主控开关始终可用 | 默认只见 switch 主控开关；点卡片箭头后出现提示文字与该通道高级按钮（箭头转向下），再点收起；各通道互不影响 |
| F2.8 | 控制状态同步 | 继电器**物理状态**经 WebSocket 广播，多页面/多浏览器一致；**路数与接线视角均为各客户端本地偏好**（localStorage），逻辑显示由各实例按本地视角独立推导 | 任一页面操作后，其余页面物理状态在 1 秒内同步；各实例可显示不同路数范围与不同逻辑视角，互不干扰 |
| F2.9 | 多实例操作提示 | 每个 GUI 实例持久化唯一标识（GUI-XXXX），请求携带 X-Client-Id 头；打开/关闭串口、继电器操作、自定义指令发送、序列启停等操作，服务端向所有页面广播"谁（标识+客户端 IP）做了什么"。**继电器操作文案以结果物理值为准**：`将通道【X】的物理值设置为：[00/01]，通路状态 [NC ：开/关，NO：开/关]`；批量操作物理值一致时汇总为`通道【1-N】`，不一致时逐通道列出 | toast 在浏览器窗口底部提示并自动消失，本机操作标注"本机"；双实例互见对方操作与物理值、两种接线视角含义 |

## 3. 数据监视窗口

| 编号 | 功能 | 说明 | 验收标准 |
|------|------|------|----------|
| F3.1 | 默认隐藏 | 监视窗口默认折叠，通过控制面板按钮展开/收起 | 展开前后不影响控制功能 |
| F3.2 | 收发数据分向显示 | 每条记录独立一行，含：时间戳（`HH:MM:SS.mmm`）、方向标记（TX 发送 / RX 接收，颜色区分）、数据内容 | 打开串口的初始化查询、面板控制、自定义指令、手动发送、序列发送——**所有串口收发字节**均如实出现在窗口中；反馈超时时的半帧数据同样显示 |
| F3.3 | 显示模式切换 | HEX 模式（`A0 01 03 A4`）/ 文本模式（可打印字符直接显示，不可打印以 `.·` 占位）可切换 | 两种模式即时切换且历史记录同步变换显示 |
| F3.4 | 自定义发送 | 十六进制输入框 + 发送按钮，支持 `A0 01 03 A4`、`a00103a4`、`A0,01,03` 等分隔格式；非法输入即时提示 | 发送内容出现在 TX 记录；串口未打开时按钮禁用并提示 |
| F3.5 | 回显容量控制 | 前端保留最近 1000 条记录，自动滚动到底部（用户上翻时暂停自动滚动）；**服务端同样保留最近 1000 条日志，浏览器接入/刷新时自动回放历史**，晚打开的页面也能看到初始化查询等既往数据 | 页面刷新或后打开，监视窗口仍显示既往收发记录 |

## 4. 自定义指令序列

| 编号 | 功能 | 说明 | 验收标准 |
|------|------|------|----------|
| F4.1 | 指令编辑 | 可添加多条自定义指令（十六进制），每条可设置发送后延迟（毫秒），可删除、可上下调整顺序 | 指令列表经 localStorage 持久化 |
| F4.2 | 顺序发送 | 按序号顺序发送所有指令，每条发送后等待其配置的延迟再发下一条；**指令或反馈被识别为合法继电器帧（0xA0 起始且校验通过）时，同步更新通道状态并广播**，循环执行期间面板状态实时跟随 | 执行顺序与序号一致；间隔与配置一致（±50ms）；循环取反/开关序列执行时通道面板状态逐次刷新 |
| F4.6 | 自定义发送同步状态 | 监视窗口手动发送的继电器指令同样解析并同步通道状态（反馈帧优先，无反馈指令按语义推断；取反且无反馈时保持原状态） | 手动发送 A0 01 03 A4 后通道面板状态同步为物理 01 |
| F4.3 | 循环模式 | 两种模式：固定循环次数（1~9999）、无限循环 | 固定次数执行完毕自动停止；无限循环持续到手动停止 |
| F4.4 | 启动/停止 | 启动后按钮变为"停止"；停止请求在当前指令执行完后尽快生效 | 停止后串口可立即用于其他操作；执行期间显示轮次进度 |
| F4.5 | 执行互斥 | 序列执行期间串口写入排队串行化，与面板控制、手动发送不冲突 | 并发操作无数据交错损坏 |

## 6. 非功能需求

| 编号 | 项目 | 要求 |
|------|------|------|
| N1 | 部署形态 | 单二进制，无外部依赖；默认监听 `127.0.0.1:8080`，可用 `-addr` 参数覆盖 |
| N2 | 并发安全 | 串口独占资源，所有 I/O 在单一执行协程中串行化；多 WebSocket 客户端并发安全 |
| N3 | 超时控制 | 反馈读取超时 200ms；原始发送后的回读窗口 300ms；所有串口读操作必须带超时；所有串口操作（打开/关闭/指令/raw/序列单条）等待上限 3s，超时返回明确错误 |
| N4 | 持久化范围 | 仅浏览器 localStorage（参数、自定义指令、UI 偏好）；服务端不落盘 |
| N5 | 健壮性 | 设备热拔出时自动关闭端口并广播错误；非法协议帧（校验错）在监视窗口如实显示但不影响状态机 |
| N6 | 前端实时性 | 打开串口后立即广播端口状态（逐路查询后台执行）；打开/关闭按钮带 pending 态与乐观更新；WebSocket 断线显示重连提示，恢复后自动拉取权威状态；静态资源带内容哈希版本号 + `no-store`，杜绝浏览器缓存陈旧资源；**启动顺序为先取权威状态再接入 WS，且带版本守卫丢弃过期状态快照**，避免快照与 WS 广播并发导致的状态回退（Firefox 时序下曾偶发） |

## 7. 明确不做（本期范围外）

- 服务端配置文件持久化 / 多配置方案管理
- Web 界面鉴权（默认仅监听本机回环地址）
- 定时任务调度（非序列循环类）
- 除继电器协议外的其他设备协议解析（监视窗口 raw 收发可覆盖简单调试场景）
