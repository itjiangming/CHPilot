# CHPilot 使用说明

> CHPilot —— 基于 CH340 USB 串口协议指令的继电器控制服务
> 开发者：JiangMing / 江明（itjiangming@163.com）

## 1. 软件简介

CHPilot 通过 CH340 USB 转串口芯片向继电器模块发送十六进制控制指令，实现跨平台（Windows / Linux / macOS）的继电器开关控制。程序为**单二进制 Go 服务**，Web 界面已内嵌其中，无需安装任何额外依赖；浏览器即开即用，支持多客户端同时查看，状态自动同步。

**主要功能一览**

| 功能 | 说明 |
|------|------|
| 串口设备管理 | 自动枚举本机串口并标记 CH340 设备（VID/PID 识别）；**热插拔自动监听**，插入/拔出设备数秒内自动更新列表 |
| 串口参数配置 | 波特率（默认 9600）、数据位（默认 8）、停止位（默认 1）、校验位（默认无）、流控制（None） |
| 继电器控制 | 支持 1/2/4/8 路模块，每路独立 开/关/取反，支持全部开启/关闭；打开串口后自动查询各路状态 |
| NO/NC 接线映射 | 按接线方式（常开/常闭）自动翻译"逻辑开/关"与物理指令，界面始终呈现真实通断语义 |
| 数据监视窗口 | 实时显示每条收发数据：时间戳、方向（TX/RX）、HEX 或文本显示；支持手动发送任意 HEX 指令 |
| 自定义指令序列 | 多条指令按序循环发送（固定次数或无限循环），每条可设延迟，可随时停止 |
| 多客户端同步 | 所有浏览器页面实时同步串口状态、继电器状态与数据流 |

## 2. 安装与启动

### 2.1 获取程序

`dist/` 已按平台分目录，每个目录内含该平台二进制与启动脚本（脚本按 CPU 架构自动选择二进制）：

| 目录 | 二进制 | 启动脚本 |
|------|--------|----------|
| `dist/windows/` | `chpilot-windows-amd64.exe`、`chpilot-windows-arm64.exe` | `start-local.bat`（仅本机）、`start-lan.bat`（局域网） |
| `dist/linux/` | `chpilot-linux-amd64`、`chpilot-linux-arm64` | `start-local.sh`、`start-lan.sh` |
| `dist/macos/` | `chpilot-macos-amd64`、`chpilot-macos-arm64` | `start-local.sh`、`start-lan.sh` |

`dist/README.txt` 有各平台的简要启动说明。

也可从源码构建：`./build.sh`（需要 Go 1.23+，产物输出到 `dist/`）。

### 2.2 启动

```bash
# 方式一：用启动脚本（推荐，自动匹配 CPU 架构）
./start-local.sh     # 仅本机访问（默认，最安全）
./start-lan.sh       # 允许局域网访问（服务无鉴权，仅限可信网络）

# 方式二：直接运行二进制并自定义监听地址
./chpilot-linux-amd64 -addr 127.0.0.1:8080   # 仅本机
./chpilot-linux-amd64 -addr :8080            # 局域网
```

Windows 下双击 `start-local.bat` / `start-lan.bat` 即可（局域网模式首次启动需在防火墙提示中勾选“专用网络”并允许）。

启动后浏览器访问 `http://127.0.0.1:8080`（局域网访问用 `http://<主机IP>:8080`）。

### 2.3 CH340 驱动

- **Windows**：多数新版系统已内置驱动；若设备管理器看不到 CH340，请安装官方驱动 [CH341SER.EXE](https://www.wch.cn/downloads/CH341SER_EXE.html)。
- **Linux**：内核自带 `ch341` 驱动，插入设备即出现 `/dev/ttyUSB0`。
- **macOS**：较新系统已内置；异常时同样安装 WCH 官方驱动。

### 2.4 Linux 串口权限

普通用户访问串口需要 `dialout` 组权限（报错"无串口访问权限"时）：

```bash
sudo usermod -aG dialout $USER
# 注销并重新登录后生效
```

## 3. 界面操作说明

### 3.1 连接串口

1. **串口设备**：下拉框列出本机串口，CH340 设备会标注"（CH340）"；设备列表自动刷新（热插拔监听），也可点"刷新"手动枚举。
2. **参数**：一般保持默认 9600 / 8 / 1 / 无校验 / None 即可（市售 CH340 继电器模块出厂默认）。
3. 点 **打开串口**：状态灯变绿、按钮变为"关闭串口"。打开失败时红色提示条显示具体原因（权限、占用、设备不存在、驱动异常等）。
4. 用完点 **关闭串口** 释放设备。程序退出（含 Ctrl+C）也会自动关闭，不会残留占用。

> 所有配置会自动保存在浏览器本地（localStorage），下次打开自动恢复。

### 3.2 控制面板

- **模块路数**：按继电器板实际路数选择 1/2/4/8，面板显示对应数量的通道卡片，并自动逐路查询当前状态。
- **每路通道卡片**（从上到下）：
  - 状态灯（绿=逻辑开、灰=逻辑关）与状态文字（"?"=状态未知，查询无反馈）；
  - **接线**：该通道的接线视角 NC（常闭，默认）/ NO（常开）——**每个浏览器独立保存、独立显示**，切换即时生效（无需重新查询）；界面状态随视角实时重映射，并附物理状态标注（物理00=线圈释放/物理01=线圈吸合）；
  - **switch 主控开关**：主要控制方式，点击即切换该通道逻辑开/关，状态以硬件反馈为准；
  - 高级按钮（默认收起，展开后按钮上方标注“独立指令下发：”）：开 / 关 / **切换**，通过**每张通道卡片右上角的箭头图标 ▸/▾** 独立展开或收起。
- **接线方式语义**：
  - **NC（常闭）**：受控负载接在常闭端——逻辑"开" = 继电器释放（COM—NC 通），默认。
  - **NO（常开）**：受控负载接在常开端——逻辑"开" = 继电器吸合（COM—NO 通）。
  - 多人/多窗口各自设置接线视角互不影响、独立显示；但对同一物理继电器，任何一方的开关操作都会同时影响两条线（NO/NC 反相），这是继电器物理特性。
- **全部开启 / 全部关闭**：按通道顺序逐路执行（各通道按自己的接线方式映射）。
- **刷新状态**：重新逐路查询所有通道。

### 3.3 数据监视窗口

默认折叠，点击"数据监视窗口 ▸"展开。用于查看串口底层收发明细、调试自定义设备：

- 每行格式：`时间戳  方向  数据`。`TX ▲`（蓝色）= 发送，`RX ▼`（绿色）= 接收。
- **显示模式**：HEX（`A0 01 03 A4`）/ 文本（不可打印字符以 `·` 占位），切换即时生效。
- **发送框**：输入 HEX 指令点"发送"（或回车）。支持宽松格式：`A0 01 03 A4`、`a00103a4`、`A0,01,03`、`0xA0 0x01` 均可。
- 最多保留最近 1000 条；跟踪到底部时自动滚动，上翻查看历史时暂停自动滚动。

### 3.4 自定义指令序列

批量/循环发送场景（如轮询、闪烁演示）：

1. **＋ 添加指令**：每行一条，填 HEX 指令和发送后的延迟（毫秒，最小 50ms 生效）。
2. 用 ↑ ↓ 调整顺序，✕ 删除。序号即执行顺序。
3. **循环模式**：固定次数（1~9999 次）或无限循环。
4. **▶ 开始发送**：按序循环执行；执行中按钮变为 **■ 停止**，点击后当前指令执行完即停，顶部显示轮次进度。
5. 执行期间其他面板操作会排队串行执行，不会与序列数据交错。

### 3.5 多客户端说明

多个浏览器/设备同时打开页面时：

- 任一页面打开/关闭串口、切换继电器，所有页面实时同步；
- 重复打开同一端口不会报错（幂等处理）；
- 串口为独占资源，所有指令在服务端排队串行执行；
- **操作提示**：页面底部会弹出 toast 显示"谁做了什么"（操作者标识 = GUI 编号 + 客户端 IP，如 `GUI-3F2A@192.168.1.5`），本机操作标注"本机"。继电器操作以**结果物理值**描述，并同时给出两种接线视角的含义，例如：`将通道【1】的物理值设置为：[01]，通路状态 [NC ：关，NO：开]`；批量操作物理值一致时汇总为`通道【1-4】`，否则逐通道列出；顶栏右侧显示本机标识，便于多人协作时辨认；
- 同一浏览器的多个标签页共享同一实例标识与接线视角偏好；不同浏览器/设备相互独立。

## 4. 控制协议参考

指令帧 4 字节：`A0 + 通道号(01~FE) + 操作码 + 校验和`，校验和 = 前三字节之和取低 8 位。

| 操作码 | 含义 |
|--------|------|
| `0x00` / `0x01` | 关 / 开（无反馈） |
| `0x02` / `0x03` | 关 / 开（带反馈，界面控制使用） |
| `0x04` | 取反（带反馈） |
| `0x05` | 查询状态（带反馈） |

反馈帧同构：`A0 + 通道号 + 0x00(关)/0x01(开) + 校验和`。例：第 1 路查询 `A0 01 05 A6` → 回 `A0 01 00 A1`（关）。

## 5. 常见问题（FAQ）

| 现象 | 原因与处理 |
|------|-----------|
| 下拉框没有设备 | 检查 USB 线与设备管理器/`lsusb` 是否有 CH340；装驱动（见 2.3）。插入设备后列表会在 2 秒内自动刷新 |
| 打开报"无串口访问权限"（Linux） | `sudo usermod -aG dialout $USER`，注销重登 |
| 打开报"被其他程序占用" | 关闭占用该端口的串口调试工具；或重启本软件（会自动释放） |
| 提示"串口操作超时" | 底层驱动长时间无响应（常见于劣质 CH340 芯片或系统休眠唤醒后）：重新插拔 USB 设备后重试 |
| 页面顶部提示"连接已断开，正在重连" | 浏览器与本地服务的连接中断（如电脑休眠、服务重启），恢复后自动重连并刷新状态；若持续出现请确认服务进程仍在运行。注意：标签页在后台时浏览器会节流定时器，重连可能延迟——**切回该标签页会立即重连** |
| 状态显示"?"（状态未知） | 发送查询后 200ms 内无硬件反馈：检查波特率是否 9600、模块是否供电、线路是否松动 |
| 点开关无反应但监视窗口有收发 | 确认接线方式 NO/NC 是否选反；确认模块供电与继电器指示灯 |
| 拔出设备后 | 页面自动显示"设备已拔出"并断开；重新插入后下拉框自动出现，点打开即可恢复 |
| 界面显示与实际不符（升级后） | 强制刷新页面（Ctrl+F5）。正式版本已通过资源版本号（`?v=哈希`）与 no-store 双重防缓存，正常不会出现 |
| 图标不显示（Linux 应用菜单） | 运行 `dist/linux/install-desktop.sh` 安装图标与启动项；浏览器标签图标由服务内嵌提供，无需配置 |
| 想把设置恢复初始 | 顶栏点「一键重置」：清除本机保存的参数/路数/接线视角/自定义指令/界面偏好/实例标识并自动重载（不影响串口开关状态与其他客户端；如有指令序列在跑请先停止） |
| 局域网无法访问 | 启动时需 `-addr :8080`；并检查防火墙。⚠️ 服务无鉴权，仅建议在可信网络使用 |
