# 基于CH340 USB 串口协议指令控制

## 需求概述
基于CH340 usb 串口通讯控制指令，做一个跨平台的串口控制程序，方案是：单二进制 Go 服务 + 内嵌 Web 页面。

‌配置参数‌：设置波特率（BaudRate）、数据位（DataBits，通常8）、停止位（StopBits，通常1）、校验位（Parity，通常无校验）以及流控制（FlowControl）。
‌打开端口‌：根据操作系统指定正确的端口名称。
‌Linux‌: /dev/ttyUSB0, /dev/ttyS0 等。
‌macOS‌: /dev/cu.usbserial-xxx（注意使用 cu. 开头而非 tty.，以避免被系统控制台占用）。
‌Windows‌: COM3, COM4 等（注意大小写敏感性，部分库要求大写）。
‌数据读写‌：
‌写入 (Write)‌：将字节切片发送到底层缓冲区。注意某些设备需要特定的结束符（如 \r\n）。
‌读取 (Read)‌：从缓冲区读取数据。‌关键点‌：默认的 Read 是阻塞的，必须设置超时（Timeout），否则程序可能永久卡死。
‌资源释放‌：程序中断或者退出，务必调用 Close() 关闭端口，否则会导致“device busy”错误，阻碍下次连接。

## 控制协议
 USB 继电器模块（如 1/2/4/8 路 CH340 继电器板）用十六进制指令控制：

1. 发送开关指令协议：
- 数据1：起始标志，固定0xA0
- 数据2：开关地址码，0x01-0xFE 表示1-254路开关
- 数据3：操作数据，如下：
  - 0x00: 关，不反馈
  - 0x01：开，不反馈
  - 0x02：关，反馈
  - 0x03：开，反馈
  - 0x04：自动取反开关，反馈
  - 0x05：查询状态，反馈
- 数据4：校验码（低8位），（数据1 + 数据2 + 数据3）% 0x100

2. 反馈数据
反馈格式和发送格式相同：数据1,2,4意义相同，仅仅数据3有差异，只有开和关，如：0x00关，0x01开。
通过查询指令返回也是一样的；
反馈示例（第一路）：
- A0 01 00 A1 关 
- A0 01 01 A2 开

## GUI 要求
1. 根据串口的枚举，选择串口设备
2. ‌配置参数，参数默认值：
   - 波特率（BaudRate）：默认值9600
   - 数据位（DataBits）：默认8
   - 停止位（StopBits）：默认1
   - 校验位（Parity）：无校验
   - 流控制（FlowControl）：none
   - 打开模式： READ/Write
3. 打开和关闭串口按钮，如果失败，提示原因
4. 选择第几路开关：当前支持1/2/4/8路，默认1路，选择后通过协议读取开关状态
5. 选择接线端口设置：NO、 NC、 COM接线，选择NC端口，开指令或者状态其实是关操作，关指令和状态是开操作，选择NO 则反之
6. 基于当前选择的电路（通道X），显示电路状态和控制开关：开/关 
7. 数据显示窗口,可选 HEX 显示，原始数据，文本数据显示，数据流方向（发送，接收）同时显示时间戳分行独立显示每个方向的数据；具备自定义发送指令的发送输入框和发送按钮；此窗口用于查看串口发送和接收数据详细信息，通过控制面板按钮点击显示，默认不显示。 
8. 增加一个拓展功能，可以自定义增加多个自定义指令，可以选择多个指令，按照序号顺序循环发送（每个指令可以配置延迟）
