使用说明

快速上手

顶栏「一键重置」：清除本机保存的设置（串口参数、路数、接线视角、自定义指令、界面偏好、实例标识）并恢复初始状态；不影响串口开关状态与其他客户端。

  1. 插入 CH340 串口设备（设备列表约 2 秒内自动刷新，也可点"刷新"）；
  2. 选择串口（CH340 设备有标注），参数保持默认 9600-8-无校验；
  3. 点"打开串口"，状态灯变绿后在控制面板操作；
  4. 用完点"关闭串口"释放设备。

控制面板

  • 模块路数：按开关模块实际路数选 1/2/4/8，打开串口后自动逐路查询状态；
  • switch 主控开关：每通道的主要控制方式，点击切换逻辑开/关，状态以硬件反馈为准；
  • 箭头图标 ▸ / ▾（通道卡片右上角）：展开/收起该通道的 开、关、切换 按钮（默认收起，每通道独立）；
  • 接线（每路独立）：NO=常开（逻辑开=吸合）；NC=常闭（逻辑语义反转：界面"开"=物理断开，默认）。按实际接线选择，修改后自动重新查询；
  • 全部开启/关闭：按通道顺序逐路执行；"刷新状态"重新查询所有通道。

数据监视窗口

  • 默认折叠，点"数据监视窗口"展开；每行：时间戳 + 方向（TX▲发送 / RX▼接收）+ 数据；
  • 显示模式可切 HEX / 文本；最多保留 1000 条；
  • 发送框支持宽松 HEX 格式：A0 01 03 A4、a00103a4、A0,01,03 均可，回车即发送。

自定义指令序列

  • "＋ 添加指令"添加多条 HEX 指令，每条可设发送后延迟（毫秒，最小 50ms 生效）；
  • ↑ ↓ 调整顺序，按序号顺序发送；循环模式：固定次数或无限循环；
  • 执行中可点"停止"，当前指令执行完即停。

多客户端

多个浏览器同时打开时，串口状态、通道开关状态、数据流实时同步；重复打开同一串口不会报错。

指令协议定义

串口参数默认 9600-8-N-1。指令帧为定长 4 字节：

A0（起始标志） + 通道号（01~FE，即第 1~254 路） + 操作码 + 校验和（前三字节之和取低 8 位）

  • 操作码：0x00 关（无反馈）、0x01 开（无反馈）、 0x02 关（带反馈）、0x03 开（带反馈）、 0x04 取反（带反馈）、0x05 查询状态（带反馈）
  • 反馈帧结构与下发帧相同，仅操作码位表示物理状态： 0x00 物理关（线圈释放）、0x01 物理开（线圈吸合）
  • 面板控制默认使用带反馈指令确认状态（开 0x03 / 关 0x02）， "切换"使用 0x04，"刷新状态"与打开串口后的初始化查询使用 0x05； 反馈读取超时 200ms，超时则该路显示"状态未知"
  • 示例（第 1 路）：查询 A0 01 05 A6 → 反馈 A0 01 00 A1（物理关）/ A0 01 01 A2（物理开）； 吸合 A0 01 03 A4；断开 A0 01 02 A3；取反 A0 01 04 A5
  • 任意通道推算：第 N 路 = A0 N 操作码 + 校验和， 如第 4 路查询 A0 04 05 A9、第 8 路吸合 A0 08 03 AB
  • 监视窗口的手动发送与自定义指令序列按原始字节下发，不受面板逻辑限制； 若字节构成合法协议帧（A0 起始且校验通过），会自动同步对应通道状态

常见问题

  • 没有设备：检查 USB 与驱动（见"关于"中的驱动链接）；插入后列表自动刷新；
  • 无访问权限（Linux）：sudo usermod -aG dialout $USER 后重新登录；
  • 被占用：关闭其他串口调试工具后重试；
  • 状态未知（?）：200ms 内无硬件反馈，检查波特率是否 9600、模块供电与接线；
  • 开关行为反了：该通道接线方式 NO/NC 选反了。

CHPilot v-

基于 CH340 USB 串口协议指令的设备控制服务。单二进制 Go 服务 + 内嵌 Web 页面，跨平台（Windows / Linux / macOS）。

主要功能：串口设备枚举与热插拔监听、串口参数配置（波特率/数据位/停止位/校验位）、 1/2/4/8 路开关独立控制（每通道独立 NO/NC 接线映射、switch 主控开关、全开全关）、 收发数据实时监视（HEX/文本、时间戳、方向标记）、自定义指令序列循环发送、多客户端状态同步。
